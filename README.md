# فاصلة — دورة HTML وCSS وJavaScript بالعربية

موقع تعليمي ثابت: HTML وCSS وJavaScript فقط. لا إطار عمل، لا مكتبات، لا خطوة بناء.
يُفتح `index.html` فيعمل كل شيء، ويُخدم كما هو من أي استضافة ملفات ثابتة.

## الصفحات

| الملف | ماذا فيه |
|---|---|
| `index.html` | الفهرس: ثلاثة وعشرون درسًا في ست وحدات، وخريطة الموقع |
| `start.html` | من أين تبدأ، وخطة أول أسبوع |
| `thinking.html` | كيف يفكّر المبرمج قبل أن يكتب |
| `lessons/01…20` | الدروس، كل درس باختبار من أربعة أسئلة |
| `challenges.html` | عشرون تحديًا يُكتب فيها الكود ويُفحص في المتصفح |
| `lab.html` | مختبر: ثلاث لوحات ومعاينة حيّة |
| `practice.html` | اختبار الوحدة الأولى وبطاقات مراجعة |
| `glossary.html` | ٣٨ مصطلحًا بشرح مبسّط |
| `dialogues/01–02` | حوارات «لماذا لا يعمل كودي؟» |
| `privacy.html` | سياسة الخصوصية |

## كيف يعمل بلا خادم

- **فحص التحديات** يجري في `iframe` معزول (`sandbox="allow-scripts"`)، وتُعاد النتيجة عبر `postMessage`. لا يُرسل شيء إلى أي مكان.
- **التقدّم** يُحفظ في هذا المتصفح وحده (`localStorage`)، ويمكن محوه من زر «إعادة الضبط».
- **لا حساب، لا تسجيل، لا تتبّع، ولا ملفات ارتباط.**

## الأذونات والتقنيات الخارجية

- الخطوط (`IBM Plex`) مرفقة داخل `assets/fonts/` وتُخدَم من الموقع نفسه: لا اتصال بأي خدمة خطوط.
- لا شيء يُحمَّل من الإنترنت عند فتح أي صفحة.

## حقوق المحتوى

الشرح والأمثلة مكتوبة لهذا الموقع. يجوز الاقتباس للاستخدام التعليمي مع ذكر المصدر، ولا يجوز إعادة النشر الكامل لأغراض تجارية دون إذن.
